# Password Generator

A simple, lightweight password generator built with Python (Flask), HTML, CSS, and JavaScript.

## How to Run

1. Make sure Python is installed and install Flask if you haven't already:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python main.py
   ```

3. Open your browser and go to:
   [http://127.0.0.1:5000](http://127.0.0.1:5000)

---

### Terminal (CLI) Mode
If you prefer running it directly inside the terminal without a browser:
```bash
python main.py --cli
```
