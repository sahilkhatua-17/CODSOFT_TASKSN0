# Contact Book

A small desktop contact manager built with Python, Tkinter and SQLite.

## Features
- Add, view, search, update and delete contacts.
- Save a name, phone number, email address and postal address.
- Search by name or phone number.
- Keep contacts between app sessions using a local SQLite database.

## Requirements
- Python 3.9 or newer
- Tkinter (usually included with standard Python installations)

## Run
Open a terminal in this folder and run:

```bash
python main.py
```

The `contacts.db` file is created automatically the first time the app starts.
